## Getting Started

Dragonfish is built entirely in Rust via the [Leptos](https://leptos.dev/) framework. Rust is available on most modern operating systems, and installation instructions are available at [the official website](https://rust-lang.org/).

### Prerequisites
* Rust 1.91 (nightly)
* PostgreSQL 18
* Redis (latest)
* Bun (latest)

After installing the latest Rust nightly and cloning this repo, grab the following tools:
* `rustup toolchain install nightly`
* `rustup target add wasm32-unknown-unknown`
* `cargo install --locked cargo-leptos`
* `cargo install trunk`

For installing PostgreSQL and Redis, please follow your platform's instructions to do so.
